Защищенные эндпоинты (требуется токен авторизации)

Для вызова требуется заголовок Authorization: Bearer TKXXXXX

Основная обработка и анализ
POST /api/v1.1/works/calc

Основная обработка

curl -X POST "http://localhost:8080/api/v1.1/works/calc" -H "Authorization: Bearer TK12345" -H "Content-Type: application/json" -d "{\"data\": [10.5, \"строка\", 20.0, null, 45.3]}"
Ответ, ошибка 
{
  "message": "Ошибка валидации: элемент не является числом",
  "response_time": "2026-10-09 12:33:05",
  "input": {
    "data": [10.5, "строка", 20.0, null, 45.3]
  },
  "data": {}
}
Ответ, успех 
{
  "message": "успешно выполнено",
  "response_time": "2026-10-09 12:33:02",
  "input": {
    "data": [10.5, 20.0, 45.3]
  },
  "data": {
    "count": 3,
    "mean": 25.26,
    "median": 20.00,
    "mode": "None",
    "variance": 213.94,
    "std_deviation": 14.62
  }
}

Сессии и профили
GET /api/v1.1/auth/profile

Статус сессии, роль и остаток TTL

curl -X GET "http://localhost:8080/api/v1.1/auth/profile" -H "Authorization: Bearer TK12345"
Ответ 
{
  "data": { "username": "user1", "role": "admin", "expires_at": "2026-10-09 12:18:45" },
  "response_time": "2026-10-09 12:15:40"
}
POST /api/v1.1/auth/refresh

Продление токена доступа

curl -X POST "http://localhost:8080/api/v1.1/auth/refresh" -H "Authorization: Bearer TK12345"
Ответ 
{
  "data": {
    "username": "user1",
    "role": "admin",
    "expires_at": "2026-10-09 12:18:45"
  },
  "response_time": "2026-10-09 12:15:40"
}
GET /api/v1.1/auth/users

Просмотр учетных записей, доступно только для admin и owner.

curl -X GET "http://localhost:8080/api/v1.1/auth/users" -H "Authorization: Bearer TK12345"
Ответ 
{
  "data": [
    {"username": "admin1", "role": "admin"},
    {"username": "user1", "role": "user"}
  ],
  "response_time": "2026-10-09 12:16:00"
}
PUT /api/v1.1/auth/users/password

Смена пароля

curl -X PUT "http://localhost:8080/api/v1.1/auth/users/password" -H "Authorization: Bearer TK12345" -H "Content-Type: application/x-www-form-urlencoded" -d "username=user1&new_password=newSecure777"
Ответ 
{
  "success": true,
  "data": { "message": "Пароль изменен" },
  "response_time": "2026-10-09 12:16:05"
}
DELETE /api/v1.1/auth/users

Удаление учетной записи

curl -X DELETE "http://localhost:8080/api/v1.1/auth/users" -H "Authorization: Bearer TK12345" -H "Content-Type: application/x-www-form-urlencoded" -d "username=user2"
Ответ 
{
  "success": true,
  "data": { "message": "Учетная запись удалена" },
  "response_time": "2026-10-09 12:16:10"
}
Администрирование
GET /api/v1.1/admin/stats

Чтение системного текстового лога действий сервера (доступно ролям admin и owner).

curl -X GET "http://localhost:8080/api/v1.1/admin/stats?limit=1" -H "Authorization: Bearer TK12345"
Ответ 
{
  "limit": 1,
  "offset": 0,
  "total_records": 45,
  "response_time": "2026-10-09 13:00:30",
  "data": [
    "[2026-10-09 12:00:01] Конфигурация .env успешно загружена"
  ]
}
GET /api/v1.1/admin/run-tests

Запуск движка автотестирования для проверки стабильности математических модулей.

curl -X GET "http://localhost:8080/api/v1.1/admin/run-tests" -H "Authorization: Bearer TK12345"
