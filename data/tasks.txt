Вариант 1. Модуль предиктивной оценки юнит-экономики (Unit Economics Engine)
Тема: Проектирование компонента анализа маржинальности цифрового продукта.
Входные параметры и ограничения:
  - price (double) - цена единицы товара. Ограничение: price >= cogs 1.05
  - cogs (double) - себестоимость производства единицы товара. Ограничение: cogs > 0.0
  - cac (double) - стоимость привлечения одного клиента. Ограничение: cac >= 0.01
  - conversion_rate (double) - конверсия посетителей в покупатели (в %). Ограничение: 0.0 < conversion_rate <= 100.0
  - churn_rate (double) - ежемесячный отток клиентов (в %). Ограничение: 0.0 < churn_rate <= 100.0
Формулы для расчетов (C++):
  - ltv = (price - cogs) / (churn_rate / 100.0)
  - ltv_to_cac_ratio = ltv / cac
  - marginal_profit = 1000.0 (conversion_rate / 100.0) (price - cogs) - (1000.0 (conversion_rate / 100.0) cac)
Пример контракта (Вход -> Выход):
  - Вход: price = 150.0, cogs = 50.0, cac = 20.0, conversion_rate = 2.5, churn_rate = 5.0
  - Выход: ltv = 2000.0, ltv_to_cac_ratio = 100.0, marginal_profit = 2000.0

Вариант 2. Компонент расчета окупаемости рекламных инвестиций (ROAS & ROMI Tracker)
Тема: Проектирование сервиса сквозной аналитики эффективности маркетинга.
Входные параметры и ограничения:
  - marketing_spend (double) - бюджет рекламной кампании. Ограничение: marketing_spend >= 1000.0
  - attributed_revenue (double) - выручка с кампании. Ограничение: attributed_revenue >= 0.0
  - agency_fee (double) - фиксированная комиссия агентства. Ограничение: agency_fee >= 0.0
  - production_cost (double) - затраты на производство креативов. Ограничение: production_cost >= 0.0 и (agency_fee + production_cost) <= marketing_spend 2.0
  - period_days (int) - длительность кампании в днях. Ограничение: 1 <= period_days <= 365
Формулы для расчетов (C++):
  - roas = attributed_revenue / marketing_spend
  - net_marketing_profit = attributed_revenue - (marketing_spend + agency_fee + production_cost)
  - romi_percentage = (net_marketing_profit / (marketing_spend + agency_fee + production_cost)) 100.0
Пример контракта (Вход -> Выход):
  - Вход: marketing_spend = 10000.0, attributed_revenue = 25000.0, agency_fee = 1500.0, production_cost = 500.0, period_days = 30
  - Выход: roas = 2.5, net_marketing_profit = 13000.0, romi_percentage = 108.33

Вариант 3. Анализатор пожизненной ценности когорт пользователей (Cohort LTV Predictor)
Тема: Проектирование модуля предиктивного когортного анализа для SaaS.
Входные параметры и ограничения:
  - initial_cohort_size (int) - изначальный размер когорты. Ограничение: initial_cohort_size >= 100
  - average_check (double) - средний чек одной покупки. Ограничение: average_check > 0.0
  - purchase_frequency_monthly (double) - среднее кол-во покупок в месяц. Ограничение: 0.05 <= purchase_frequency_monthly <= 31.0
  - retention_month_1 (double) - % удержания в 1-й месяц. Ограничение: 0.0 <= retention_month_1 <= 100.0
  - decay_rate (double) - скорость падения удержания (в %). Ограничение: 0.0 < decay_rate <= 100.0
Формулы для расчетов (C++):
  - half_life_months = log(0.5) / log(1.0 - (decay_rate / 100.0))
  - clv = 0.0; double current_ret = retention_month_1 / 100.0; запустить цикл от 1 до 12 месяцев: { clv += average_check purchase_frequency_monthly current_ret; current_ret *= (1.0 - (decay_rate / 100.0)); }
  - predicted_total_revenue = initial_cohort_size clv
Пример контракта (Вход -> Выход):
  - Вход: initial_cohort_size = 1000, average_check = 50.0, purchase_frequency_monthly = 1.0, retention_month_1 = 80.0, decay_rate = 10.0
  - Выход: half_life_months = 6.58, clv = 287.03, predicted_total_revenue = 287030.45

Вариант 4. Оптимизатор динамического ценообразования (Dynamic Pricing Core)
Тема: Проектирование алгоритма адаптивного изменения цен под воздействием внешних факторов.
Входные параметры и ограничения:
  - base_price (double) - базовая цена. Ограничение: base_price > 0.0
  - competitor_price (double) - цена ключевого конкурента. Ограничение: competitor_price >= base_price 0.2
  - current_stock (int) - текущий товарный остаток на складе. Ограничение: current_stock >= 0. Если current_stock == 0, сразу генерировать исключение.
  - demand_surge_factor (double) - коэффициент всплеска спроса. Ограничение: 0.5 <= demand_surge_factor <= 5.0
  - min_allowable_margin (double) - минимально допустимая маржа (в %). Ограничение: 0.0 <= min_allowable_margin <= 90.0
Формулы для расчетов (C++):
  - scarcity_multiplier = (current_stock < 10) ? 1.25 : 1.0
  - optimized_price = base_price demand_surge_factor scarcity_multiplier
  - Корректировка: если (optimized_price < competitor_price 0.95) optimized_price = competitor_price 0.95; если (optimized_price < base_price (1.0 + min_allowable_margin / 100.0)) optimized_price = base_price (1.0 + min_allowable_margin / 100.0);
Пример контракта (Вход -> Выход):
  - Вход: base_price = 100.0, competitor_price = 110.0, current_stock = 5, demand_surge_factor = 1.2, min_allowable_margin = 10.0
  - Выход: optimized_price = 150.0

Вариант 6. Анализатор возврата инвестиций в IT-инфраструктуру (ROI & Payback Estimator)
Тема: Проектирование экспертной системы оценки капиталовложений в аппаратное/программное обеспечение.
Входные параметры и ограничения:
  - capital_expense (double) - капитальные затраты. Ограничение: capital_expense >= 1000.0
  - implementation_cost (double) - стоимость внедрения и обучения. Ограничение: implementation_cost >= 0.0
  - monthly_savings (double) - ежемесячное сокращение издержек. Ограничение: monthly_savings > 0.0
  - operating_cost (double) - ежемесячная стоимость техподдержки решения. Ограничение: operating_cost >= 0.0 и monthly_savings >= operating_cost 1.1
  - target_period_months (int) - горизонт планирования в месяцах. Ограничение: 3 <= target_period_months <= 120
Формулы для расчетов (C++):
  - total_investment = capital_expense + implementation_cost
  - payback_period_months = total_investment / (monthly_savings - operating_cost)
  - roi_percentage = (((monthly_savings - operating_cost) target_period_months - total_investment) / total_investment) 100.0
Пример контракта (Вход -> Выход):
  - Вход: capital_expense = 8000.0, implementation_cost = 2000.0, monthly_savings = 1500.0, operating_cost = 500.0, target_period_months = 24
  - Выход: payback_period_months = 10.0, roi_percentage = 140.0

Вариант 7. Вычислительный модуль лизинговых платежей (Lease Annuity Calculator)
Тема: Проектирование финансового ядра обработки лизинговых сделок для b2b-сектора.
Входные параметры и ограничения:
  - asset_value (double) - рыночная стоимость приобретаемого имущества. Ограничение: asset_value > 0.0
  - down_payment (double) - первоначальный авансовый платеж. Ограничение: 0.0 <= down_payment <= asset_value 0.9
  - lease_term_months (int) - срок договора лизинга в месяцах. Ограничение: 6 <= lease_term_months <= 84
  - annual_interest_rate (double) - годовая ставка (в %). Ограничение: 1.0 <= annual_interest_rate <= 150.0
  - residual_value (double) - выкупная стоимость имущества в конце срока. Ограничение: 0.0 <= residual_value <= asset_value 0.2
Формулы для расчетов (C++):
  - r = annual_interest_rate / (12.0 100.0)
  - s = asset_value - down_payment
  - monthly_payment = (s r pow(1.0 + r, lease_term_months) - residual_value r) / (pow(1.0 + r, lease_term_months) - 1.0)
  - total_overpayment = (monthly_payment lease_term_months) + down_payment + residual_value - asset_value
Пример контракта (Вход -> Выход):
  - Вход: asset_value = 100000.0, down_payment = 20000.0, lease_term_months = 12, annual_interest_rate = 12.0, residual_value = 10000.0
  - Выход: monthly_payment = 6303.49, total_overpayment = 5641.87

Вариант 8. Модуль оценки средневзвешенной стоимости капитала (WACC Calculator)
Тема: Проектирование компонента оценки стоимости корпоративного финансирования.
Входные параметры и ограничения:
  - market_value_equity (double) - рыночная стоимость собственного капитала. Ограничение: market_value_equity > 0.0
Используйте код с осторожностью.
market_value_debt (double) - рыночная стоимость заемного капитала. Ограничение: market_value_debt > 0.0 и market_value_equity + market_value_debt >= 100000.0
cost_of_equity (double) - требуемая доходность по собственному капиталу (в %). Ограничение: 0.1 <= cost_of_equity <= 100.0
cost_of_debt (double) - процентная ставка по долговым обязательствам (в %). Ограничение: 0.1 <= cost_of_debt <= 100.0
tax_rate (double) - ставка налога на прибыль (в %). Ограничение: 0.0 <= tax_rate <= 70.0
Формулы для расчетов (C++):
	v = market_value_equity + market_value_debt
	equity_weight = market_value_equity / v
	debt_weight = market_value_debt / v
	wacc_percentage = (equity_weight (cost_of_equity / 100.0) + debt_weight (cost_of_debt / 100.0) (1.0 - (tax_rate / 100.0))) 100.0
Пример контракта (Вход -> Выход):
	Вход: market_value_equity = 600000.0, market_value_debt = 400000.0, cost_of_equity = 15.0, cost_of_debt = 10.0, tax_rate = 20.0
	Выход: equity_weight = 0.6, wacc_percentage = 12.2

Вариант 9. Оценщик чистой приведенной стоимости проекта (NPV & Profitability Indexer)
Тема: Проектирование инвестиционного ядра многокритериального анализа проектов.
Входные параметры и ограничения:
	initial_investment (double) - стартовые инвестиции в проект. Ограничение: initial_investment > 0.0
	annual_cash_flow (double) - ожидаемый ежегодный чистый приток денежных средств. Ограничение: annual_cash_flow > 0.0
	discount_rate (double) - ставка дисконтирования (в %). Ограничение: 0.5 <= discount_rate <= 100.0
	project_lifetime_years (int) - срок жизни проекта в годах. Ограничение: 1 <= project_lifetime_years <= 50
Формулы для расчетов (C++):
	npv = 0.0; запустить цикл от t=1 до project_lifetime_years: { npv += annual_cash_flow / pow(1.0 + (discount_rate / 100.0), t); } npv -= initial_investment;
	profitability_index = (npv + initial_investment) / initial_investment
	is_viable = (npv >= 0.0)
Пример контракта (Вход -> Выход):
	Вход: initial_investment = 50000.0, annual_cash_flow = 15000.0, discount_rate = 10.0, project_lifetime_years = 5
	Выход: npv = 6861.80, profitability_index = 1.137, is_viable = true

Вариант 10. Модуль дисконтирования и оценки будущей стоимости (Future Value Processor)
Тема: Проектирование вычислительного компонента для сложных финансовых начислений.
Входные параметры и ограничения:
	present_value (double) - текущая сумма денежных средств. Ограничение: present_value >= 100.0
	annual_rate (double) - номинальная годовая процентная ставка (в %). Ограничение: 0.1 <= annual_rate <= 200.0
	years (int) - срок размещения капитала в годах. Ограничение: 1 <= years <= 50

Формулы для расчетов (C++):

	total_compound_interest = future_value - present_value
	inflation_adjusted_value = future_value / pow(1.0 + 0.05, years)
