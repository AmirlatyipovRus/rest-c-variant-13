Расчет статистических характеристик числовой последовательности

Программа обрабатывает массив вещественных чисел и вычисляет среднее арифметическое, медиану, моду, генеральную дисперсию и среднеквадратичное отклонение.

Требования к блоку обеспечения стабильности работы системы:
1. Объем выборки: от 2 до 100 чисел
2. Диапазон: каждое число от -1000 до 1000 (защита от аномалий и переполнения)
3. Валидация: ошибка при посторонних символах, разделителях или пустых элементах (null)

Параметры

Параметр Назначение По умолчанию Обязательный
Authorization Токен сессии (Header: Bearer TKXXXXX) Нет Да
data Входной JSON-массив чисел для выполнения вычислений в теле запроса Нет Да
date_from Начальная дата фильтрации логов и истории (формат YYYY-MM-DD) Не ограничена Нет
date_to Конечная дата фильтрации логов и истории (формат YYYY-MM-DD) Не ограничена Нет
limit Количество возвращаемых записей в одном ответе пагинации 20 Нет
offset Смещение выборки для постраничного вывода (пропуск строк) 0 Нет
target_group Фильтрация истории по роли пользователей (массив строк, например ["user"]) [] Нет
username Идентификатор аккаунта для CRUD / логина Нет Да
password Пароль для аутентификации или создания записи Нет Да

Открытые эндпойнты, без токена доступа

GET /api/v1.1/counters

Показатели системы: количество аккаунтов, успешных расчеток и ошибок

curl -X GET "http://localhost:8080/api/v1.1/counters"
Пример ответа 
{
  "data": {
    "total_users": 4,
    "total_successful_calculations": 142,
    "total_failed_validations": 18
  },
  "response_time": "2026-10-09 12:53:15"
}

POST /api/v1.1/auth/register

Регистрация в системе

curl -X POST "http://localhost:8080/api/v1.1/auth/register" -H "Content-Type: application/json" -d "{\"username\": \"newuser\", \"password\": \"securepass789\"}"
Пример ответа при успешной регистрации 
{
  "success": true,
  "data": {
    "message": "Пользователь newuser успешно зарегистрирован.",
    "role": "user"
  },
  "response_time": "2026-10-09 13:28:00"
}
Пример ответа, если имя уже занято 
{
  "success": false,
  "data": {
    "message": "Ошибка регистрации: имя пользователя 'newuser' уже занято в системе."
  },
  "response_time": "2026-10-09 13:28:03"
}
POST /api/v1.1/auth/login

Вход в систему (аутентификация)

curl -X POST "http://localhost:8080/api/v1.1/auth/login" -H "Content-Type: application/json" -d "{\"username\": \"user1\", \"password\": \"pass123\"}"
Пример ответа 
{
  "success": true,
  "data": {
    "token": "TK48291",
    "role": "admin",
    "ttl_seconds": 300,
    "created_at": "2026-10-09 12:53:00",
    "expires_at": "2026-10-09 12:58:00"
  },
  "response_time": "2026-10-09 12:53:00"
}
